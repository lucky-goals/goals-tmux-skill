## 5. Key Implementation Caveats Discovered

1. **Cursor `agent acp` process exit & session persistence (`2026.11.11-b912975`):** `agent acp` (and `kiro-cli acp` v3) did not exit within 3s of stdin EOF and required `SIGTERM` (`rc=143`), whereas `agy acp` and `kiro-cli acp --agent-engine v2` exited cleanly with `rc=0` on stdin EOF. Additionally, Cursor's `agent acp` `session/load` could not reload sessions across processes despite advertising `loadSession: true`.
2. **Agy headless `-p` syntax (`1.5.8`):** `agy -p` consumes its next argument as the prompt string (`-p "<prompt>"`), not as a boolean flag (`p0c_agy_headless.json` vs `p0c_agy_headless_ok.json`).
3. **Claude headless multi-turn `result` frames with subagents:** When a background `Task` subagent completes, `claude -p --output-format stream-json` can emit multiple `type: "result"` lines in a single process lifetime (`p0f_claude_hl_subagent.json`). Supervisors must read until stdout EOF rather than stopping on the first `result` line.
4. **Kiro vendor-prefixed ACP notifications:** `kiro-cli acp` emits `_kiro/*` (v3) and `_kiro.dev/*` (v2) JSON-RPC notifications alongside `session/update`. Normalizers should ignore `_`-prefixed vendor notifications (or map them separately) so they do not trip `adapter_unknown`.
